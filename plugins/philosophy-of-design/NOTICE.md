# Notice and attribution

## What this plugin is built on

The skills, subagents and output styles in this plugin are original work by Nouran Darwish. They are built on the
**A Philosophy of Software Design** rule sets published in [ciembor/agent-rules-books](https://github.com/ciembor/agent-rules-books) by Maciej Ciemborowicz
(upstream commit `893a88a6fce3a80c565bf39ac65021b43a8b2990`).

The three files in `skills/principles/references/` are unmodified copies of the upstream `a-philosophy-of-software-design` rule sets:

| File here | Upstream file |
| --- | --- |
| `full.md` | `a-philosophy-of-software-design/a-philosophy-of-software-design.md` |
| `mini.md` | `a-philosophy-of-software-design/a-philosophy-of-software-design.mini.md` |
| `nano.md` | `a-philosophy-of-software-design/a-philosophy-of-software-design.nano.md` |

They are redistributed under the upstream MIT license, reproduced below as that license requires.
