# Notice and attribution

## Built on

Every plugin in this repository is built on the rule sets published in
[ciembor/agent-rules-books](https://github.com/ciembor/agent-rules-books) by **Maciej Ciemborowicz**, released under the MIT License.
Each plugin vendors, unmodified, the upstream `full`, `mini` and `nano` rule files for its book in
`plugins/<slug>/skills/principles/references/`, and records the upstream commit it copied from in `plugins/<slug>/NOTICE.md`.

The skills, subagents, output styles, scripts and documentation around those files are original work by Nouran Darwish, also under the MIT License.
